# Запустить «по-настоящему» (бесплатно) — пошагово

Цель: реальные аккаунты, регистрация, и чтобы в панели работодателя было видно всех.
Нужен только бесплатный **Supabase** (это «память»/сервер). Никакого Hetzner.

---

## Ваша часть (≈10 минут, всё бесплатно)

### 1. Создать проект Supabase
1. Зайдите на <https://supabase.com> → **Start your project** → войдите (можно через GitHub или email).
2. **New project** → придумайте имя (напр. `tooaeg`), задайте пароль базы (запишите его), регион — **Frankfurt** (ближе к Эстонии). Create.
3. Подождите ~2 минуты, пока проект поднимется.

### 2. Создать таблицы (одна вставка)
1. Слева **SQL Editor** → **New query**.
2. Откройте файл [supabase/setup_all.sql](supabase/setup_all.sql), скопируйте **всё** содержимое, вставьте в редактор.
3. Нажмите **Run** (внизу). Должно написать «Success».

### 3. Включить регистрацию
1. Слева **Authentication → Providers → Email**.
2. Убедитесь, что **Email** включён.
3. Выключите **Confirm email** (чтобы регистрация срабатывала сразу, без письма). Save.

### 4. Скопировать 3 ключа
Слева **Project Settings → API**, скопируйте и пришлите мне:
- **Project URL** (вида `https://xxxx.supabase.co`)
- **anon public** ключ
- **service_role** ключ (секретный — нужен только серверной части панели)

> anon-ключ безопасен в приложении (его защищает RLS). service_role — секрет, живёт только на сервере панели, в телефон не попадает.

---

## Моя часть (после того как пришлёте ключи)
1. Пропишу ключи в `apps/mobile/.env` и `apps/admin/.env.local`.
2. Перезапущу веб-приложение работника — демо-режим выключится сам, появится вход/регистрация.
3. Запущу панель работодателя локально (`localhost:3000`).

## Проверяем вместе живой круг
1. Панель (`localhost:3000`) → вкладка **«Loo ettevõte»** → создаёте компанию → получаете **код компании**.
2. Приложение работника → **«Создать аккаунт»** → вводите этот код → регистрируетесь.
3. Жмёте **«Начать смену»**.
4. Обновляете панель → работник виден «в смене», на карте, часы считаются. 🎉
