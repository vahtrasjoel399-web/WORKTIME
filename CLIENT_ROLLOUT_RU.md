# WorkTime: запуск для администратора и работников

## 1. Что должно быть опубликовано

Перед передачей приложения клиенту владелец системы должен:

1. Отправить последние коммиты в `origin/main`.
2. Дождаться успешного deployment проекта Vercel с Root Directory `apps/admin`.
3. Применить все миграции Supabase, включая
   `supabase/migrations/0020_managed_accounts_and_accountant_role.sql`:

   ```bash
   supabase login
   supabase link --project-ref <SUPABASE_PROJECT_REF>
   supabase db push
   ```

4. В Supabase оставить включённым Email signup: он нужен владельцу для создания
   новой компании. Работник через этот поток зарегистрироваться не может — RPC
   присоединения работника отключён миграцией.
5. Проверить переменные Vercel для `apps/admin`:

   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `NEXT_PUBLIC_SITE_URL`

`SUPABASE_SERVICE_ROLE_KEY` является секретом. Его нельзя отправлять клиенту,
добавлять в mobile-приложение или публиковать в Git.

После нового deployment веб-сайт использует одну WorkTime-иконку: favicon во
вкладке браузера, Apple Touch Icon и PWA-иконки 192×192/512×512.

## 2. Как создать компанию и войти первый раз

1. Открыть production-адрес WorkTime: `<АДРЕС_АДМИН_ПАНЕЛИ>`.
2. Выбрать **Создать компанию**.
3. Ввести название компании, имя и фамилию владельца, электронную почту и пароль.
4. Нажать **Создать компанию**.
5. Если Supabase требует подтверждение почты, открыть письмо и подтвердить адрес.
6. Вернуться на WorkTime, выбрать **Войти** и использовать ту же почту и пароль.

Создавший компанию пользователь становится её администратором. Вкладки
«Я работник» нет: работники не создают себе аккаунты самостоятельно.

## 3. Как поставить веб-приложение на главный экран

### Android — Chrome

1. Открыть `<АДРЕС_АДМИН_ПАНЕЛИ>` в Google Chrome.
2. Нажать меню **⋮**.
3. Выбрать **Установить приложение** или **Добавить на главный экран**.
4. Подтвердить установку.
5. На главном экране появится WorkTime с тёмной иконкой и жёлтым кольцом.

### iPhone/iPad — Safari

1. Открыть `<АДРЕС_АДМИН_ПАНЕЛИ>` именно в Safari.
2. Нажать **Поделиться** — квадрат со стрелкой вверх.
3. Прокрутить меню и выбрать **На экран «Домой»**.
4. Проверить название WorkTime/Tööaeg и нажать **Добавить**.

### Компьютер — Chrome/Edge

1. Открыть production-адрес WorkTime.
2. Нажать значок установки справа в адресной строке или открыть меню браузера.
3. Выбрать **Установить WorkTime**.

Если после deployment осталась старая иконка, удалить старый ярлык с главного
экрана, обновить страницу и добавить приложение заново. Favicon браузера также
может требовать жёсткого обновления страницы или открытия в приватном окне.

## 4. Как администратор создаёт работника

1. Открыть админ-панель и войти под администратором.
2. Открыть **Сотрудники**.
3. Нажать **Добавить пользователя**.
4. Выбрать роль **Сотрудник**.
5. Заполнить имя, фамилию и электронную почту.
6. Задать временный пароль длиной минимум 10 символов.
7. При необходимости выбрать объект, ставку, фотографию и CV.
8. Нажать **Создать аккаунт**.
9. Передать работнику только:

   - ссылку для установки приложения;
   - его электронную почту;
   - временный пароль.

Код компании работнику больше не нужен. Самостоятельной регистрации нет.

## 5. Как администратор создаёт бухгалтера

1. Нажать **Добавить пользователя**.
2. Выбрать роль **Бухгалтер**.
3. Ввести имя, фамилию, электронную почту и временный пароль.
4. Нажать **Создать аккаунт**.

Бухгалтер входит через веб-панель. Он видит список сотрудников и отчёты, но не
видит карту/GPS, документы, объекты и административное редактирование.

## 6. Как подготовить нативное приложение работнику

В `apps/mobile` должны быть production-переменные Supabase:

- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_ANON_KEY`

Для Android можно создать ссылку на устанавливаемый APK:

```bash
cd apps/mobile
eas login
eas build -p android --profile preview
```

После сборки EAS покажет ссылку. Эту ссылку можно отправить работнику.

Для публикации в Google Play / App Store:

```bash
eas build -p android --profile production
eas build -p ios --profile production
eas submit -p android --latest
eas submit -p ios --latest
```

Для iPhone удобнее отправлять работнику приглашение TestFlight после загрузки
production-сборки в App Store Connect.

## 7. Готовое сообщение владельцу компании

> Здравствуйте! Ваша панель WorkTime доступна по адресу:
> `<АДРЕС_АДМИН_ПАНЕЛИ>`.
>
> При первом запуске выберите «Создать компанию», заполните данные компании и
> владельца, затем подтвердите электронную почту, если придёт письмо.
>
> После входа откройте «Сотрудники» → «Добавить пользователя». Выберите роль
> «Сотрудник» или «Бухгалтер», введите почту и временный пароль. Сам работник
> аккаунт не создаёт, код компании ему не нужен.
>
> Чтобы поставить WorkTime на главный экран:
> — Android/Chrome: меню ⋮ → «Установить приложение»;
> — iPhone/Safari: «Поделиться» → «На экран Домой».
>
> Бухгалтер видит только сотрудников и отчёты. Карта, GPS, документы, объекты и
> административное редактирование ему недоступны.

## 8. Готовое сообщение работнику

> Здравствуйте! Для работы используется приложение WorkTime.
>
> 1. Установите приложение по ссылке: `<ССЫЛКА_НА_ПРИЛОЖЕНИЕ>`.
> 2. Откройте приложение.
> 3. Введите электронную почту: `<ПОЧТА_РАБОТНИКА>`.
> 4. Введите временный пароль: `<ВРЕМЕННЫЙ_ПАРОЛЬ>`.
> 5. Разрешите геолокацию при использовании приложения. Местоположение
>    фиксируется только при начале и завершении смены, а не постоянно.
> 6. Для начала работы нажмите «Начать смену», для завершения — «Закончить смену».
>
> Самостоятельно создавать аккаунт и вводить код компании не нужно. Если вход
> не работает, обратитесь к администратору.

Пароль лучше передавать отдельно от ссылки на приложение и не публиковать в
общем рабочем чате.

## 9. Контрольная проверка перед передачей клиенту

- На веб-странице есть вход и создание новой компании, но нет регистрации работника.
- В mobile нет кнопки создания аккаунта и входа по SMS.
- Случайный Auth-пользователь без активного профиля `worker` не входит в mobile.
- Работник, созданный администратором, входит по выданной почте и паролю.
- Бухгалтер открывает только **Сотрудники** и **Отчёты**.
- Работник не видит админ-панель.
- Миграция `0020` применена на production Supabase.
- Во вкладке браузера и после добавления на главный экран отображается новая
  WorkTime-иконка с жёлтым кольцом.
