# Быстрый старт на телефоне (демо-режим, без бэкенда)

Хотите просто увидеть приложение на своём телефоне? Три шага.

## 1. Один раз — поставить Node.js
Скачайте **Node.js 20 LTS**: https://nodejs.org → установите → **перезапустите терминал**.

## 2. Поставить Expo Go на телефон
- **Android:** «Expo Go» в Google Play
- **iPhone:** «Expo Go» в App Store

## 3. Запустить
В PowerShell:
```powershell
cd c:\begin\apps\mobile
./try-on-phone.ps1
```
Появится **QR-код**:
- **Android** — откройте Expo Go → Scan QR code
- **iPhone** — наведите обычную Камеру, нажмите на всплывающую ссылку

Телефон и компьютер — в одной Wi-Fi сети. Если не подключается, нажмите Ctrl+C и запустите `npx expo start --tunnel`.

---

## Что можно потрогать в демо
- **Начать смену** → приложение спросит доступ к GPS (разрешите) → пойдёт живой таймер, дуга «дышит».
- **Перерыв**, затем **Закончить смену** → выедет карточка с итогом.
- **Мои часы** — смена появится в списке, сумма за месяц.
- **Настройки** — смените язык (ET/RU/EN/FI), тему, ставку €/час, включите/выключите заработок.

Всё работает **прямо на телефоне**, данные хранятся локально. Регистрация и вход не нужны — демо-режим включается сам, когда не настроен Supabase.

## Когда захотите «по-настоящему» (с сервером и веб-панелью)
Тогда нужен бесплатный проект Supabase — полная инструкция в [README.md](README.md). Демо-режим отключится автоматически, как только впишете реальные ключи в `apps/mobile/.env`.
